# Contributing

Keep the launcher small, native and free of network permissions. Put network fetching in the optional companion. Preserve essential remote controls, signature-protect provider data, and keep all redirects opt-in. Do not commit device dumps, local configurations, keys, APKs or screenshots containing personal details. Run `testReleaseUnitTest lintRelease assembleRelease` in `launcher/` and verify behavior on a real device before making compatibility claims.
